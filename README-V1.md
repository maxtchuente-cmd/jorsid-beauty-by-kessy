# Jorsid Beauty by Kessy — V1

Archive de fichiers applicatifs à copier dans un projet Laravel fraîchement créé. Elle ne contient ni Laravel/vendor, ni `.env`, ni base de données.

## Installation
1. Créer le projet Laravel, installer Livewire et Spatie Translatable, puis `npm install`.
2. Copier les dossiers `routes` et `resources` de cette archive dans la racine du projet.
3. Exécuter `npm run build`, `php artisan optimize:clear`, puis `php artisan serve`.
4. Ouvrir http://127.0.0.1:8000.

## Inclus
Accueil responsive, prestations de démonstration, à propos, contact de démonstration, navigation partagée et identité visuelle violet/rose/bleu ciel.

## Pas encore inclus
Base de données métier, administration authentifiée, catalogue administrable, réservation réelle, disponibilités, e-mails et paiements. Ils sont prévus pour les versions suivantes. Le formulaire de contact n'envoie pas de message.
